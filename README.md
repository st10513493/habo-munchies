# HABO MUNCHIES

## About the Website
HABO MUNCHIES is a food website for a small shop selling affordable South African meals.

## Products
- Cheese Burger – R55
- Kota Special – R45
- Large Chips – R30

## Website Features
- Responsive website design
- Food menu with dynamic content
- Search functionality
- Interactive FAQ section
- Contact form with JavaScript validation
- SEO optimisation

## Technologies Used

- CSS
- JavaScript
